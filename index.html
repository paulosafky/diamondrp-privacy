1. About this bot

The Diamond RP bot is a private Discord application used only in the official Diamond RP Discord server, a GTA V (FiveM) roleplay community. It is not available to other servers. This policy explains what data the bot processes, why, and how long it is kept.

2. Data we process

3. Message content

The bot only reads message content inside ticket channels, to build the transcript when a ticket is closed. It does not read, store or analyse messages anywhere else, and message content is never stored outside Discord.

4. What we do not do

  • We do not sell, rent or share your data with third parties.
  • We do not use any data to train machine learning or AI models.
  • We do not track presence or activity outside the Diamond RP server.

5. Security

Data is stored on a dedicated server with restricted access, available only to the Diamond RP management team.

6. Your rights

You can ask to see or delete the data we hold about you by opening a ticket in the Diamond RP Discord server. Leaving the server removes your boost/tag perk record automatically. Some records, such as moderation transcripts, may be kept where necessary to enforce server rules.

7. Changes

We may update this policy. The date at the top always shows the latest version.

3. Conteúdo das mensagens

O bot só lê o conteúdo das mensagens dentro dos canais de ticket, para criar a transcrição quando o ticket fecha. Não lê, não guarda e não analisa mensagens em mais nenhum sítio, e o conteúdo nunca é guardado fora do Discord.

4. O que não fazemos

  • Não vendemos, alugamos nem partilhamos os teus dados com terceiros.
  • Não usamos dados para treinar modelos de machine learning ou de IA.
  • Não seguimos a tua presença nem a tua atividade fora do servidor do Diamond RP.

5. Segurança

Os dados ficam num servidor dedicado com acesso restrito, só disponível à administração do Diamond RP.

6. Os teus direitos

Podes pedir para ver ou apagar os dados que temos sobre ti abrindo um ticket no Discord do Diamond RP. Ao saíres do servidor, o registo de perks de boost ou tag é apagado automaticamente. Alguns registos, como transcrições de moderação, podem ser mantidos quando forem necessários para aplicar as regras do servidor.

7. Alterações

Esta política pode ser atualizada. A data no topo indica sempre a versão mais recente.
